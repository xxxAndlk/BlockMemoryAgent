## 5.2 接口族与 Registry 结构

- `Tool`：`Name()/Aliases()/Execute(ctx,args) *Result`——**无 error 返回**，失败编码进 Result；Dispatch 的 error 只用于哨兵（ErrLoopExit）与未知工具。
- `SchemaSource`（可选）：`Description() string + InputSchema() *jsonschema.Schema`——实现它即被 Schema() 动态兜底路径包装（MCP 插件工具走这条）。
- `DestructiveTool`（可选）：`Destructive() bool`——接审批链。
- Hook 族（反向接线）：`MediaResolveFunc`/`AskUserHookFunc`/`AskUserBatchHookFunc`/`EscalateGearHookFunc`/`UserProfileHookFunc`/`KnowledgeSearchHookFunc`/`ApprovalHookFunc`/`ToolVisibilityFunc`。
- `Registry` 关键字段：`exec`/`progress`/`failures`、`mu`（tools/aliases/schemaOrder）、`readMu`（per-scope 读状态：lastReadKey/sameReadCount/longFileScopes/fileReadMtime）、`sharedMemory`、`refresher`、`fileMap`、`approvalHook`/`productionWorkDir`/`approvalDisabled`、`roleToolGate`、`pluginMgr`/`pluginVisibility`、`mountedMu`+`mounted`+`preMounted`（配置声明的顶层必备预挂集，与 mounted 取交集）。
- `Result`：Tool/Success/Output/Error/Images（json:"-"）/Artifacts/Category（`validation_rejected`/`execution_failed`（默认）/`empty_result`）。

## 5.3 Dispatch 完整流程（15 步）

`registry.go:532-755`：

1. **别名解析**：tools[name] → aliases[name] → 未知报错。
2. emitTool 事件（进度回调前置）。
3. **roleToolGate 硬闸**（如注入）：白名单=角色静态 tools ∪ 角色可见插件工具；不在集内 → 工具级错误（不终止循环）。
4. **ReadFile 同读检测**：键 `cleanPath\x00offset\x00limit`；连读达 3 次（长文件 6 次）→ **ErrLoopExit**；第 2 次给 args 注入 readNote 提示。
5. **审批判定** `needsApproval`（信任模式 + 动态破坏性 + 危险命令）→ hook：error 直接上抛；false=工具级拒绝；nil hook 跳过（fail-open）。
6. WithSessionID 注入 ctx。
7. **陈旧写提示**（EditFile/WriteFile）：fileReadMtime 与磁盘现 mtime 不一致 → 附"文件已被外部修改"（advisory 不阻断）。
8. `t.Execute`。
9. **ReadFile 后处理**：readNote 追加；输出含"共 N 行"且 N>500 → 标记长文件 scope（阈值改 6）；追加 mtime 提示。
10. **写成功钩子**（res.Success）：`invalidateSharedMemoryForPath`（重扫共享记忆，命中路径的 spec 槽**写 tombstone**、普通槽置 InvalidatedAt）→ `resetSameReadForPath` → staleWriteNote → recordFileMtime → `scheduleProjectRefresh`（3s 去抖）。
11. 文件地图 touch。
12. **RunCommand 影响文件判定**（rm/mv/mkdir/touch/cp 或 git rm/mv）→ scheduleProjectRefresh。
13. fillResult（SessionID/ArgsJSON 截 300 暴露给回调）。
14. **失败计数**：成功 resetValidation；validation_rejected 特例——**meta 的 call_sub_agent(s) 豁免计数**（防拒绝循环）；否则 failValidation ≥5 → ErrLoopExit（附原始错误文本）。
15. emitResult 事件。

**失败计数器**：键 `scope\x00name`（scope=AgentID 优先，否则 SessionID）——同会话多 Agent 天然隔离；reset 挂在成功路径（2026-09-09 事故：reset 无调用点导致进程级累积误杀会话）。

## 5.4 Schema 生成与注册

三个来源按序拼装：①静态内建块（读/写/编辑/恢复/ListDir/RunCommand/SearchInFiles/HTTPVisit/Git 四件套/RefreshProjectDoc/共享记忆/WriteSpec）；②条件内建块（call_sub_agent/send_message/submit_plan/review_plan/create_role/list_roles/list_models/set_role_model/pause_agent/resume_agent/set_agent_model——先判存在再注入，描述动态组装）；③**动态兜底循环**：未覆盖且实现 SchemaSource 的工具（插件工具免桥接直出）。

- **保序**：按注册顺序（schemaOrder）输出 → LLM 缓存前缀不抖。
- `Register` 写三处；`Unregister` 三处同步删；`ToolNames` 返回 schemaOrder 拷贝（供 roleToolGate 廉价读，不锁死热路径）。
- 新加静态块必须把名字加进 `covered`，否则同工具出双份 schema。
- Adapter 层（agent/tool_adapter.go）过滤 = 静态白名单 ∪（插件可见 ∩ 已挂载）；**Dispatch 不受白名单限制**（verifyloop 的 ExecuteChild 直接走 inner.Dispatch）。

## 5.5 Guard 链

`GuardRegistry`：注册顺序=执行顺序，**首个报错短路**。

写守卫（默认 5 个，顺序敏感——protected-path 必须最先）：

1. **protectedPathGuard**：拒写受保护目录（`.git/.github/.idea/.vscode/node_modules/dist/build/bin/logs/.cache`——**只匹配顶层段**避免子串误伤）。
2. **mailboxFileGuard**：文件名含 mailbox + .json + 前缀（to-/from-/msg-/mailbox/mail-/send-/notify-）→ 拒（防伪造邮箱）。
3. **fileHelperScriptGuard**：内容嗅探（.py 的 open+read+print / os.walk / 循环读；.sh 的 cat/ls/grep+echo）→ 拒（防脚本绕读文件限制）。
4. **mailboxGoProgramGuard**：Go 程序特征 + mailbox 字样 → 拒。
5. **pathWhitespaceGuard**：路径各段不得含空格（**末段例外**；allowSpaces 透传）。

命令守卫：

6. **longRunningServerGuard**：约 50 条模式（http.server/flask/uvicorn/npm start/vite/webpack serve/django runserver/node server.js/nodemon/docker compose up/tail -f/less/man/vim/pygame/tkinter/start http/go run…）→ 拒（防阻塞命令挂死工具调用）。
7. **funcCommandGuard**（注册名 sandbox-block）：命令黑名单（见 Sandbox）。

## 5.6 Sandbox 与 ctx 键族

**默认黑名单**（`DefaultSandboxConfig`）：rm/rmdir/rd/del/erase、mv/move/ren/rename、cp/copy/xcopy/robocopy、dd/format/mkfs/fdisk/diskpart、shutdown/reboot/poweroff/halt/init、sudo/su/doas、chmod/chown/chgrp/setfacl、curl/wget/nc/netcat/telnet/ssh/scp/ftp、taskkill/kill/killall/pkill。
匹配规则：关键字必须被 `(^|[\s;&|()<>])` 与 `([\s;&|()<>]|$)` 包围（避免 preformat 误伤 format）。`SetSandboxConfig(nil)` 自动补默认黑名单（最低防护）。

**路径规则**：允许区 = 会话工作目录 + AllowedPaths；`isPathAllowed`（Clean + 前缀判定显式补分隔符，Windows 小写比较）；`sanitizeWritePath`（AllowWriteOutsideWorkDir=true 放行，否则越界报错）；`resolvePathWithSandbox`（读路径版）。临时目录 `<wd>/.bma/tmp/<sessionID>`。

**角色级写路径 Layer 4**（dormant opt-in）：`roleWritePaths` 解析器为 nil / 无 roleID / 返空 → 不限制；非空时目标必须落在至少一条路径下。

**ctx 键族**（全部在 tool 包定义）：

| 键 | 读取缺省 |
|---|---|
| SessionID | "" |
| StopContext | nil（回退 Background） |
| TrustModeFunc | **full-auto**（最宽松） |
| ImageInputSupported | **true**（最宽松） |
| RoleID | ""（角色级写路径即关闭） |
| WorkDir | ""（回退 Executor 默认 → cwd） |
| AgentID | ""（scopeKey 退化为 SessionID 级共享计数） |

**信任模式三档**：suggest（写/编辑/恢复/RunCommand/动态破坏性全审批）、auto-edit（仅 RunCommand+破坏性审批）、full-auto（全免，现状默认）。

## 5.7 审批链

- 协议：`ApprovalHookFunc(ctx, toolName, args) (bool, error)`；nil hook=全放行（fail-open）；(false,nil)=工具级拒绝；error=中止本轮（fail-closed）。
- **危险命令模式表**（`dangerousCommandPatterns`）：git push/merge/rebase/reset/clean/checkout -f/stash drop；rm -rf/-r /-f、rmdir /s|/q、rd /s、deltree、del /s|/f、erase /f、remove-item -recurse|-force；format /diskpart/shutdown/restart-computer/stop-computer；drop database/table/schema、truncate table；make install/uninstall、npm publish/unpublish、pip uninstall；kill -9/taskkill /f、net user/localgroup、sc delete、reg delete、reg add hklm；curl --request delete/-x delete、invoke-webrequest -method delete。
- 确认文案 `ApprovalMessage`：按工具定制，尾部固定"回复「确认」执行…其余答复按拒绝处理"。
- 触点在 Dispatch 步骤 5；生产实现 = ReactService.ApprovalHook。

## 5.8 内置工具逐个

- **ReadFile**：offset/limit（默认 200，上限 1000 clamp）；输出头 `[共 N 行 | 本页 X-Y 行 | mtime=... | 继续读请 …]`；maxChars 16000 截断。**注意输出头格式是同读守卫长文件判定的字面依赖**。
- **WriteFile**：内容上限 100000 runes；**缩水三态**——比例 <0.3 且旧 ≥1000B 警示；<0.10 且旧 ≥5000B **硬拒**（除非 confirm_shrink=true）（防截断级联事故）；expected_mtime 前置校验（容差 2s）；写前 `snapshotBeforeWrite`（`.bma/snapshots/<sid>/<rel>.<stamp>.bak`，保留 24h，过期清理）；temporary=true 走会话临时目录。
- **EditFile**：old==new 拒；new ≤50000 runes；CRLF 归一后计数（0 次 → **模糊回退**逐行 TrimSpace 子序列匹配 + 警告；>1 且未 replace_all → 报错列命中数）；写回保留原 CRLF。
- **RestoreFile**：全套写检查；`findSnapshot`（本会话目录优先再全库；恢复前对现状再备份）。
- **ListDir**：`D ` 前缀 + 尺寸列。
- **SearchInFiles**：大小写不敏感**字面**匹配（`|`=OR）；扩展名白名单 13 种；跳过 .git/node_modules/vendor；单文件 500 行封顶；**零命中不算失败**。
- **RunCommand**：Guard 链 → **mkdir 特判**（本地 MkdirAll 不走 shell）→ 超时 clamp 60s → shell 选择（Windows：git 同目录 bash → 常见路径 → 回落 powershell -Command + UTF-8 前缀；`isWSLBashStub` 排除 System32 假 bash）→ cmd.Dir=workDir → **进程树杀**（Windows taskkill /T + 5s 宽限）→ **三级解码**（UTF-8→GB18030→replacement）→ 端口冲突提示（--port/-p/:/末尾数字）→ 截 10000。
- **HTTPGet/HTTPPost**：1MB 读上限；输出**经 `WrapUntrusted(url, body)` 围栏**；2xx 判成功；POST 支持 JSON body 自动 Content-Type。
- **Git 四件套**：gitDiff/gitStatus/gitLog（-n 20）/gitBlame；有任意输出即算成功；截 10000。
- **静态 Destructive()=true**：WriteFile / EditFile / RestoreFile / **plugin_install**。**RunCommand 不在其中**——破坏性全靠 needsApproval 动态判（任何绕过 Dispatch 直跑 Executor 的路径都会跳过审批链）。

## 5.10 共享记忆三件套

- **shared_memory.go**：`SharedMemoryStore{Set/Get/Delete/Keys}` + CAS 扩展 `SetIfVersion`（`ErrVersionConflict`）。
  - **WriteSharedMemory**：content/agentID 必填；slot 默认 "shared"（禁 ':' 与空白）；写前 stat files 记 mtime；key=`agentID:slot`。
  - **单写者槽**：`file_tree` 仅允许一个 Agent 写（防互踩）。
  - **CAS**：maxCASAttempts=2（首次+一次重试），冲突抛给调用方不无限重试。
  - **ReadSharedMemory**：截断限 20000；前缀解析顺序=本 Agent 前缀 → 全 key 精确 → slot 唯一候选回退（多候选报歧义）。
- **shared_memory_md.go**：frontmatter（AgentID/Slot/Files map[path]mtime/Version/InvalidatedAt/**FileList/Goal/Acceptance/Constraints/VerifyLevels/Contract/Probes/Scenes/Baseline**）；`EncodeSpecMD` 渲染人类可读 MD（契约桩标 `【占位桩,责任方: X,须实装】`）；`DecodeSharedMD` 要求 `---` 开头，失败返 ok=false 不 panic。
- **shared_memory_file_store.go**：路径 `<wd>/.bma/shared/`；**ADS 防御**——slot 含危险字符（如 `spec:<key>` 的冒号=NTFS ADS 流）时**整 key hex 编码**；旧格式 `<hex>__<slot>` 兼容读；`IsGrowingPath`（logs/.bma）的 mtime 不参与失效判定。

## 5.11 spec.go + contract.go

- `Spec{Goal, Acceptance, Constraints, Files, VerifyLevels, Contract, Probes, Scenes, Baseline}`；acceptance 双形态（[]string 或 map → `FormatAcceptanceLine` 编码 `文本 [evidence:X layer:Y]`）；证据白名单 command/screenshot/probe/file/manual（空→manual）；层 functional/quality（空→functional）。
- **WriteSpec 校验**：goal 必填 + acceptance ≥1 + contract 形状校验（signature/symbol 拒 CJK 与全角字符——防拿中文当契约符号）+ **保真关键词且无基线 → 拒绝**（还原/复刻/仿制/高保真/对标/fidelity/replica/clone of/recreate）+ `baseline_content` 内联落盘（`.bma/baseline/<basename>`，只取 path.Base）+ Baseline stat 自描述核查 + **happy-path 自动追加**（命中断崖降级关键词且无 happy-path 验收时追加）；key 默认 `<agentID>:spec`，带 slot → `<agentID>:spec:<slot>`。
- `NormalizeVerifyLevels`：存在性/静态/existence/static/integration/runtime/visual + 别名（probes→runtime、scenes/screenshot→visual）。
- **Contract{symbols, dom_ids, scripts, signatures}**；`ContractSymbol{Stub, Owner}`——Stub=true 表占位桩、Owner 责任方。
- **Tombstone**：`SpecTombstonePrefix="invalidated: "`——写文件触碰 spec 记录的 Files 时，spec 槽被写成效标记（区分"被失效"与"从未写"）。

## 5.12 其余组件

- **untrusted.go**：`WrapUntrusted(source, content)`——空内容返空；source 只取首行；**转义所有 `<untrusted_data` 开闭标记**防逃逸。消费方=MCP 桥 + HTTPGet/Post + dispatcher 记忆召回/兄弟产出渲染（【相关记忆】【兄弟产出】逐条包，`source="block-memory"`）+ mailbox 转译（`source="mail:<From>"`，From=user 豁免）——后两类 2026-09-20 把防线从外部源延伸到 Agent 间通道。
- **names.go**：`BareToolName` 剥 `__` 前插件 ID。
- **loop_guard.go**：`ErrLoopExit` 唯一哨兵（同读守卫/validation 阈值/停滞守卫/循环守卫消费）。
- **mount.go + mount_tools.go**：`MountForScope` 天花板校验（未注册/非插件/超可见性各拒并留痕）；`tool_catalog`（列天花板内工具 + ✓ 已挂载）/`tool_mount`/`tool_unmount`。**预挂载**（2026-09-17）：`MountPreApprovedForScope(scope, role, names)` 免角色天花板直挂——`preMounted` 集按 scope 记录配置作者人工声明的"顶层必备"工具（插件 `top_level: true`，如 web_search），与 `mounted` **取交集**（tool_unmount 卸载后预挂随之失效）；Schema 过滤对预挂名无条件放行、执行硬门（roleToolGate）按 scope 豁免、`tool_catalog` 对预挂项标 ✓（否则天花板外的 domain 顶层看到"无工具"与实际 Schema 不符）。

## 5.14 fail-open/fail-closed 清单与坑

**fail-open（缺省放行）**：审批 hook 未接线；TrustModeOf/ImageInputSupportedOf 缺省；共享记忆引用失效仅 InvalidatedAt。
**fail-closed（缺省拒绝/报错）**：ask_user hook nil → error；审批 hook 返 error → 中止本轮；沙箱默认拒写工作目录外。
**降级不报错**：read_media 视频路径；DecodeSharedMD 失败返 ok=false。

坑：

1. **Gate/门与 Schema 三层并集**：roleToolGate 白名单是静态 tools ∪ 插件可见（不含热挂载集）；Adapter Schema 过滤是白名单 ∪（插件可见 ∩ 已挂载）——两处口径不同，别混。
2. **同读守卫键含分页参数**（换页读不触发）；长文件阈值依赖 ReadFile 输出头字面格式（改输出头静默破坏判定）。
3. **CAS 单写者槽 file_tree**；**Windows ADS** 整键 hex 编码。
4. **validation_rejected 计数豁免仅 meta 的 call_sub_agent(s)**。
5. **`WithUserInput` 不存在**（本代码库零命中，勿臆造）。
6. **视觉门控三处收口**（ReadMedia 自拦 + adapter Dispatch 剥图兜底 + 图片降采样）——改一处须同步其余。
7. **RunCommand 非静态 Destructive**（全靠 needsApproval）。
8. **`schemaOrder` = ToolNames 载荷**（不含插件热挂载集）。
9. **Adapter Dispatch 不受白名单限制**（白名单只管 Schema 暴露）。
10. **`ErrLoopExit` 是唯一循环强退信号**（四处守卫共用）。
11. **WriteFile 缩水硬拒需 confirm_shrink**（截断级联事故的防线）。
12. **tombstone 而非 delete**：spec 失效写墓碑值留痕。
