## 1.1 入口（main.go / cmd）

### backend/main.go（服务端）

flags：`-config -roles -env -soul -profile -skills -web-dist`；未显式指定 → join 到 `BMA_HOME`（`config.HomeDir()`，自定义 flag.Visit 保留显式值）。流程：早期 logger → LoadEnvFile（stat 后加载，出错 fatal）→ config.Load → `logging.Init(EntryBackend, ...)` + `log.SetOutput` → **`bootstrap.Build`（传 ProfilePath——服务端拥有完整自进化链）** → `NewDefaultRouter` → 静态（`/assets/*` immutable、favicon no-cache、NoRoute→index.html）→ http.Server（Read/WriteTimeout + IdleTimeout 120s）→ SIGINT/SIGTERM 优雅关闭（3s ctx → `app.Close()`）。

### cmd/tui/main.go

见第 12 章。与 main.go 的关键差异：

- **不传 ProfilePath**（ConfigPaths 只给 Config/Role/Env/Soul/Skill/LogWriter）→ **TUI 模式下用户画像、Evolver 自进化、技能沉淀 sink、EvolutionLogger 全部不装配**（bootstrap.go:637 的 `if paths.ProfilePath != ""` 整块跳过）——"TUI 与 server 行为不一致"的根因级差异。
- 本地 Gin `/api` 组**无鉴权中间件**；`runewidth.EastAsianWidth=false`；strict os.Stat 五文件。

### cmd/memory-console/main.go

独立 SSE 客户端控制台，**与 bootstrap 无接线**（消费 UIEvent：agent.status/graph.step/workspace.event/episode.new/stats.tick；断线 5s 重连）。

## 1.3 后台循环与钩子（哪些是 ticker，哪些是事件驱动）

其余全部是**事件驱动 hook**（bootstrap 只做装配）：

| 组件 | 触发点 | 说明 |
|---|---|---|

## 1.4 配置体系（yaml 键 ↔ 结构体）

`Config{Postgres, PgVector, Redis, HTTP, Memory, Agent, Logging, Data, Notify}`。

**加载流程**：读文件 → **深合并同目录 `infrastructure.yaml`、再 `agent-policy.yaml`**（不存在也不报错——隐式可选合并层）→ unmarshal → applyDefaults → resolveEnvVars（`${VAR}` / `${VAR:"default"}`）。

**关键段**：

- `postgres`：dsn / max_open 25 / max_idle 5 / conn_max_lifetime 300——**但 store 硬编码 20/10/1h，这些是死配置**。
- `pgvector`：dimensions 1024 / ivfflat / cosine（只有 dimensions 被用）。
- `redis`：addr（`${REDIS_ADDR:"localhost:6380"}`，db 5）/ 池参数——**除 addr/password/db 外全未接线**。
- `http`：addr 默认 **127.0.0.1:10010**；read/write_timeout 30s；`auth_enabled=true 且 token 空 → Load 返回错误`。
- `memory`：100/5/300（装配用事件存储版 pipeline）。
- `notify`：webhook_url（空=关）+ webhook_events 默认 [completed, error]。
- `data`：knowledge_archive_days 0=关 / log_retention_days 0→30 / tool_outputs_retention_days 0→14。
- `decision`（2026-09-23 TODO #23）：provider llm（默认）/http + http_url/http_api_key/http_timeout_sec 8——外部 HTTP 默认关，失败自动回退 LLM 兜底。roles.yaml 新增 `decision_model:` 节（未配置回退 lightweight）。
- `logging`：dir/enabled/format/level/timezone/stack_enabled/no_color。
- **`agent` 段（最大）**：内嵌 `LLMRuntimeConfig`（tool_call_max_rounds 50 / retry_count 3 / react_llm_timeout_sec 300 / sub_agent_timeout_min 30 / heartbeat 5 / history_max_messages 400 / tool_output_history_max_runes 2000 / summarize_keep_recent 15 / summarize_max_bundles 20 / salvage_llm_timeout_sec 120 / engine_llm_timeout_sec / token_budget_per_role / context_token_budget 150000 / paused_domain_max_resumes / domain_recon_wall_clock_min / stop_destroy_countdown_sec 300 / tool_result_dump_runes 3000 / tool_result_digest_runes 4000 / stale_tool_evict_rounds / agents_md_max_runes 4000 / tool_parallel_enabled 默认 true / tool_parallel_max_concurrency 4）、`SafetyConfig`（tool_sandbox_disabled / tool_approval_disabled / sandbox_allowed_paths / blocked_cmds / role_tool_gate_enabled / production_workdir）、`FeatureTogglesConfig`（dag_enabled / restore_sessions / block_memory_write_enabled 默认 true / max_total_dispatches 30 / spec_enforcement_enabled 默认 true / plan_confirmation_enabled 默认 true / plan_confirm_timeout_sec 600 / plan_max_revisions）、standalone 默认（context_window 32000 / read_file_max_chars 16000 / run_command_max_output 10000 / run_command_timeout_sec 60 / dispatch_retry_count 1 / reflection_max_rounds 2 / plan_execute_max_steps 8 / judge_role prompt_reviewer / image_max_edge 1024 / **trust_mode 非法回退 full-auto**、**default_gear 非法回退 daily（含 legacy auto→daily）** / worktree 默认 true / Video）；决策层（2026-09-23）decision_shadow_enabled 默认 true / decision_timeout_sec 5 / decision_points per-点 {mode, min_confidence, score_floor}（影子对拍达标逐点手动切 enforce）。
  **不存在 `sessions:` 段**——档位/信任模式都在 `agent.*`。

**.env 加载**（env.go）：逐行、跳空/`#`、取第一个 `=`、剥配对引号、**无条件 os.Setenv——.env 覆盖外部 shell 变量**（优先级约定）。

## 1.8 隐含约定与坑

1. **`ConfigPaths.ProfilePath` 为空 → 画像/自进化/技能沉淀整块不装配**（cmd/tui 恰好没传）。
2. **cleanup 是注册逆序**：Shutdown 放最后注册所以最先执行；追加 cleanup 必须往末尾加。
3. **只有 SetDefaultTrustMode/SetDefaultGear 做"配置值非法即启动失败"**；config 层的静默回退只在直接调 config.Load 的工具/测试里生效。
4. **插件 Load 失败不阻塞启动** → 启动成功不代表插件可用。
5. **RestoreSessions 失败不阻塞** → 历史会话可能静默缺失。
6. **.env 覆盖 shell env**；**infrastructure.yaml/agent-policy.yaml 是隐式可选合并层**（只看 config.yaml 会漏键）。
7. **prompts registry 键必须与 roles.yaml 严格对齐**（改名即启动报错，设计意图）。
8. **改提示词语义必须 bump Version** 并写变更记录。
9. **env.go/home.go 的解析逻辑在 main.go 与 cmd/tui 各写一遍**（非共享函数，改规则要两处同步）。
10. **cmd/tui 的 /api 无鉴权**（本地随机端口设计使然）——不要照抄它的 router 到对外服务。
11. **memory-console 与 bootstrap 解耦**：改 UIEvent 结构不会随启动失败暴露。
