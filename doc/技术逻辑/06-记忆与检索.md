## 6.1 三条记忆通路总览

真正被消费的"记忆"有三条**互不走对方存储**的通路：

1. **压缩金字塔**（会话内历史压缩）：每轮 `Assemble` 自动注入，存 PG `agent_compress_states`。
2. **块记忆**（跨会话外脑）：子 Agent 完成时沉淀到 `global_knowledge`（pgvector），派发新子 Agent 时语义召回。
3. **用户画像/项目偏好**：Markdown 文件 + persona 注入器。

另加：事件流（`agent_events` 双写）与文件小地图（任务级符号轮廓）。

## 6.2 MemoryPipeline（每轮上下文组装）

接口（agent/react_memory.go:28-34）：`Assemble(role, agentID, history) []ReactMessage`（返回**全量** messages，调用方不再追加）+ `Write(agentID, MemoryEvent) error`；`NopMemoryPipeline` 空实现。

主循环接入（react_agent.go）：每轮 `Assemble`(:619) → evictStaleToolResults → buildTimeMessage → windowMessages → sanitizeToolPairing → 预算检查。写点三处（answer :807 / tool_call :902 / sub_agent_summary :1998），**返回值一律丢弃**（失败不阻断主循环）。

`Assemble` 组装顺序（pipeline.go，从内到外）：

```
engine.Assemble（分档视图变换，#22①） → compressedView（压缩视图） → injectEvents（【近期事件】） → injectFileMap（文件小地图） → engine.AfterTurn（轮末微压缩，#22①）
```

后两者都是**尾部追加 system 消息**（不动历史前缀，保前缀缓存）。

- **engine**（#22①，context_engine.go）：分档上下文引擎槽位。nil=现状管线（daily）；fast=旧 tool result >200 rune→stub（零 LLM）；cluster=大文件 >25K rune→~200 rune 探查摘要。Assemble/AfterTurn 契约=**内容替换条数不变**（TailStart 下标依赖）；失败隔离 QuarantineEngine（panic/契约失败→按 agentID 隔离降级 daily，engine_quarantine 事件留痕）。
- **compressedView**：估算候选视图 token ≥ 预算（perRole 优先；引擎在场时 engineThreshold 覆盖——cluster 100K 更早触发）→ 引擎 Compact 或 `advanceCompression` → 重读状态重 build；`TailStart` 越界/Bundles 空 → 原样返回（fail-open）。
- **injectEvents**：取尾部 `limit` 条格式化拼接；条数 > 8 且有 summarizer 时先查 memo（fnv64a 键、cap 16）再调 LLM 摘要（失败回退原始拼接）；超 4000 rune 截断；包 `【近期事件】` 尾部追加。**审计行过滤**（`isContextHiddenEvent`：compaction/checkpoint/engine_quarantine）不进上下文——SQL 取证数据只落 store（`Write` 对审计行同样只落库不进内存事件流），防每轮变字节打断前缀缓存。
- **injectFileMap**：provider 注入的任务级文件符号轮廓。
- **Write**：内存 append（超 200 裁最旧；审计行跳过）+ 5s 超时落 PG。

**包装链**（与 Pipeline 本体叠成最多 5 段尾部注入）：meta 会话套 `boardInjectingPipeline`（board_context.go）、子 Agent 套 `siblingUptakePipeline`（blackboard_uptake.go）、meta 还叠 idle roster 与 task ledger 两个 wrapper（idle_roster_context.go / task_ledger_context.go）。**追加顺序 = 内到外 = 重要性递增**。

## 6.3 压缩金字塔

触发：**仅由 token 阈值驱动**（`summarize_every` 步频扳机已退役）；引擎在场时阈值可覆盖（cluster=100K 常驻上界）。

`advanceCompressionStyled`（pyramid.go，风格参数 compactStyle——daily=defaultCompactStyle()，cluster=LCM 参数，fast=useLLM:false 截断包零 LLM）：

1. `compressBoundary`：keepRecent（默认 15）边界 + system 前缀全保留 + 首个 user 定位 + 避开孤立 tool 结果；cluster 额外 residentMin（30K rune）向前多保消息。
2. **增量条件**：prev 状态存在且 `prev.TailStart ∈ (segStart, recentStart]` → 续压新滑出段；否则**从头重压丢弃旧包**。
3. 大文件外置（cluster）：段内 >25K rune 工具输出换 ~200 rune 探查摘要（`probeBigFiles`，幂等）。
4. `summarizeSegmentStyled`：LLM 摘要（超时/熔断/禁 LLM 降级纯截断）。摘要模板三件套（KC v0.23.0，#21①）：【已定决策】【后续步骤】【可预见的障碍】+【文件要点】，prompt 前置自盘指令（"先自盘状态再输出压缩包"，#21②）；空摘要重试一次再降级（#21③ 质量门，KC v0.3.0）；leaf 包按 leafCap 截断（cluster 1200 rune）。
5. 超 fanout（daily=20 / cluster=8）→ `mergeOldestBundlesStyled`（daily 取一半；cluster 合最老 4，condensed 包 2000 rune 收口；失败拼接截 3000 rune）。
6. 状态 upsert JSONB（`agent_compress_states`）+ **压缩审计事件**（type=compaction，#20②）：Input=压缩前快照（账本/拓扑名册/未读计数，`preCompactSnapshot`）、Content=摘要本体、Output=体积指标——直写 store 不进上下文。

**压缩生命周期钩子**（#20②，与 #21 合并落地）：压缩前快照 + **热改动重注入**（`hotReinjectProvider`：≤5 个最近改动文件、>5K tok 只回路径 + CLAUDE.md 从盘重读，冻结进视图 `HotReinject` 字段）——未提交热改动不随压缩蒸发（CC 压缩回退事故解药）。

`buildCompressedView`：`system 前缀 + 首条 user + renderBundles 摘要消息 + messages[TailStart:]`。renderBundles 尾注固定一句"精确细节查 agent_events/session_events，历史轨迹 SQL 可查"（#21② 压缩后回灌指引，KC 同款）——JIT 回灌做成内置纪律。摘要本体必须出现在压缩后视图（#21③ 交接合同，KC v0.15.0）。

**懒加载**：`loadCompressStateOnce` 每 agent 只试一次；`TailStart > len(history)` 才丢弃状态。

**摘要器 402 熔断**：`summarizerDisabled` = 连续 balance errors ≥ 2（只认 "Insufficient Balance"/"402"）；熔断后全走截断降级**直到进程重启**（无冷却恢复）。

**展开式召回**（#22④）：`Bundles(agentID)` 暴露摘要包链（leaf→condensed 副本）给 expand_memory 工具——压缩摘要讲不细时派只读展开器沿链取回细节，压缩不再等于失忆。

## 6.5 Embedding 多后端

`NewEmbedder` 分派：`""`/`pseudo` → PseudoEmbedder；`openai`/`local` → OpenAI 兼容 HTTP；`onnx` → 条件编译（`-tags onnx`）；default 报错。

- **PseudoEmbed**：SHA-256 桶计数 + L2 归一（牛顿迭代）；tokenize 小写 ASCII 词 + CJK 逐字。零依赖恒成功（离线兜底）。
- **OpenAIEmbedder**：`POST {base}/v1/embeddings`（**base_url 只写主机根路径**，客户端自拼 /v1/embeddings）；10s 超时；**3 连败 → 开路 60s**（开路期失败不计数防探测延长）；`httputil.RetryableClient`（3 次退避）；非 200/空 data/维度不匹配报错。
- **ONNX**：需 `model.onnx + tokenizer.json + config.json` 三件齐全，**缺一 fail-closed 不降级**；WordPiece 分词器（贪心最长前缀，`##` 续子词，失配回退 UNK）；mean pooling + L2；`mu` 保护 session。
- 维度自洽约束：`pgvector.dimensions` = `embed.dim` = ONNX hidden_size。

## 6.6 检索层（chunker/RRF/hybrid）

- `Chunk`（chunker.go）：按行/标题切块 + rune 重叠；空行/标题/超限硬收；**拼块时不补回 `\n`**。
- `rrfMerge`（rrf.go）：`score += 1/(60+rank+1)`，稳定排序截 topK；`byID` 是**后者覆盖前者**（最终记录对象来自最后一路）。
- `SearchHybrid`（hybrid.go）：`external_kb` 默认 type；embed 失败**直接报错**；单路失败仅 logf；两路都失败才报错。
- `IngestDir`：只处理**顶层** `.md/.txt`（不递归）；逐块 embed+Save，单块失败继续；meta 带 namespace/source/doc/chunk。
- `GlobalKnowledgeRetriever.Retrieve` 是 **dormant 路径**（依赖未接线直接报错）——真正在用的是 SearchHybrid 与 dispatcher 的 injectScopedRecall。

## 6.7 用户画像与项目偏好

- **Store**（userprofile/store.go）：RCU（读 atomic.Pointer 无锁、写 mu 串行）；文件缺失发布空 Profile 不报错；`Append` 定位/新建小节，追加 `- text（YYYY-MM-DD HH:MM）`（**全角括号**）。
- **人工行 vs 自动行**（merge.go）：尾部带时间戳 = Auto（可被合并重写）；否则 Human（原序保留在前，程序永不改写）。
- **MergePlan**：`merged` 是**完整替换**（空列表=清空该小节 Auto 行）；`archived` 进归档小节（cap 20）；`ApplyMerge` 文本相同回填旧时间戳去重。
- **ProjectStore**：按 `tool.WorkDirFromContext(ctx)` 优先解析路径（`<wd>/.bma/project_preferences.md`），per-path 缓存（**失败不缓存**，缓存只增不减）；多进程无跨进程锁。
- 演化的失败降级：merge 失败 → `Append(归档小节, 原始增量)`（fail-open 不丢）。

## 6.10 隐含约定与坑

1. **块记忆写入去重（2026-09-16）**：`bootstrap.blockMemorySaver.Save` 落库前调 `FindSimilarBlockMemory`（同 task_domain、cosine 距离 <= 0.15），命中则 `UpdateContentEmbedding` 更新既有行而非新增——同结论跨会话反复沉淀不再无限涨行；查询失败放行照常插入（best-effort）。历史遗留：存量行 `last_accessed` 仍 NULL，归档开关需手工回填后生效。
2. **事实提取口径与质量门（2026-09-16）**：输入 `truncateHeadTail` 头 4000 + 尾 2000（旧版只留头 4000，长输出的尾段结论被丢）；条数上限 `agent.block_memory_facts_max`（默认 5）；prompt 以"跨任务可复用"为判据（排除完成/验证状态、改动清单、未修改声明、清理声明、失败原文——存量实证这类占相当比例），`filterJunkFacts` 丢弃 `[failure` 条目；salvage 路径打捞 LLM 未成功且回退文本含失败标记时不落库（原先 `[failure kind=...]` 原文直落，存量 13 条已 archived）。
3. **沉淀触发门（2026-09-16 用户定向"只沉淀改动的关键逻辑与信息"）**：`saveBlockMemory` 先过 `hasSubstantiveChange`——无文件改动轨迹且全程只调只读类工具（`blockMemoryNoChangeTools` 白名单：读/搜/Git 只读/技能查询/问答/计划/控制）的任务不沉淀；白名单外的工具（插件/MCP/RunCommand/派发等）一律视为有产出。提取器已注入时其结果为权威：**提取失败与提取为空都不回退原文**（原文回退是历史噪声主源），仅未注入提取器才回退 `result.Text`。调用点 3 处（成功收尾 / token 限部分回传 / 热驻 domain 完成）均传 `history`。
4. **`truncate()` 是字节截断**（与 rune 截断并存于 pipeline.go，别混用；中文会切出乱码）。
5. **`summarize_every` 已退役**（步频压缩曾致"反复失忆重读文件"）——别重新接上。
6. **摘要器 402 熔断不可恢复**（到进程重启）；表现为"上下文全截断无结构化摘要"且日志无显式错误。
7. **`summarizeTimeout` 代码默认 5s vs config 120s**——漏装配 `WithSummarizeTimeout` 会让思考型模型摘要全挂回退全量。
8. **RRF 注释与实现不符**（最后一路覆盖同 ID 记录）。
9. **chunker 丢换行**（markdown 结构被压平）。
10. **`SearchHybrid` 降级不对称**：embed 挂=硬失败；向量库挂=关键词仍可用。
11. **`SearchBlockMemoryByGoal` 空 sessionID 静默退化为全局检索**。
12. **跨 session 阈值更严**（0.5 vs 0.4）——宁可漏不可串味。
13. **fail/partial 不丢弃**（进"避坑经验"段）——过滤掉等于丢掉最贵的教训。
14. **金字塔"从头重压丢旧包"边界**：增量条件不满足时整段重压（摘要重写、缓存失效）；改 windowMessages/evict 顺序会触碰。
15. **三段注入全尾部追加**（前缀缓存约定）；新增注入器必须遵守。
16. **`loadCompressStateOnce`/`loadEventsOnce` 每 agent 只一次**：agentID 复用（热驻换任务）不会重拉 PG 状态；陈旧状态只要 TailStart 不越界就照用。
17. **审计行不进上下文**（#20②/#22①）：compaction/checkpoint/engine_quarantine 类型经 `isContextHiddenEvent` 双重过滤（Write 只落 store + injectEvents/loadEventsOnce 跳过）——它们是 SQL 取证数据，渲染进【近期事件】会每轮变字节打断前缀缓存。
18. **引擎 Assemble/AfterTurn 契约=条数不变**（#22①）：TailStart 是 history 下标，引擎只能内容替换（stub/探查摘要）不能增删消息——契约违反被 QuarantineEngine 捕获即隔离降级 daily。
19. **记忆索引超限不静默截断**（#20③）：RenderMemoryIndex 超配额带【记忆索引超限】重写指令（CC errors#memory-index 同款）逼模型整理旧沉淀；untrusted 围栏行结构性丢弃（召回循环防护）。
