## 6.1 三条记忆通路总览

真正被消费的"记忆"有三条**互不走对方存储**的通路：

1. **压缩金字塔**（会话内历史压缩）：每轮 `Assemble` 自动注入，存 PG `agent_compress_states`。
2. **块记忆**（跨会话外脑）：子 Agent 完成时沉淀到 `global_knowledge`（pgvector），派发新子 Agent 时语义召回。
3. **用户画像/项目偏好**：Markdown 文件 + persona 注入器。

另加：事件流（`agent_events` 双写）与文件小地图（任务级符号轮廓）。

## 6.2 MemoryPipeline（每轮上下文组装）

接口（agent/react_memory.go:28-34）：`Assemble(role, agentID, history) []ReactMessage`（返回**全量** messages，调用方不再追加）+ `Write(agentID, MemoryEvent) error`；`NopMemoryPipeline` 空实现。

主循环接入（react_agent.go）：每轮 `Assemble`(:619) → evictStaleToolResults → buildTimeMessage → windowMessages → sanitizeToolPairing → 预算检查。写点三处（answer :807 / tool_call :902 / sub_agent_summary :1998），**返回值一律丢弃**（失败不阻断主循环）。

`Assemble` 组装顺序（pipeline.go:306-308，从内到外）：

```
compressedView（压缩视图） → injectEvents（【近期事件】） → injectFileMap（文件小地图）
```

后两者都是**尾部追加 system 消息**（不动历史前缀，保前缀缓存）。

- **compressedView**（:319-369）：估算候选视图 token ≥ 预算（perRole 优先）→ `advanceCompression` → 重读状态重 build；`TailStart` 越界/Bundles 空 → 原样返回（fail-open）。
- **injectEvents**（:373-465）：取尾部 `limit` 条格式化拼接；条数 > 8 且有 summarizer 时先查 memo（fnv64a 键、cap 16）再调 LLM 摘要（失败回退原始拼接）；超 4000 rune 截断；包 `【近期事件】` 尾部追加。
- **injectFileMap**（:472-485）：provider 注入的任务级文件符号轮廓。
- **Write**（:488-517）：内存 append（超 200 裁最旧）+ 5s 超时落 PG。

**包装链**（与 Pipeline 本体叠成最多 5 段尾部注入）：meta 会话套 `boardInjectingPipeline`（board_context.go）、子 Agent 套 `siblingUptakePipeline`（blackboard_uptake.go）、meta 还叠 idle roster 与 task ledger 两个 wrapper（idle_roster_context.go / task_ledger_context.go）。**追加顺序 = 内到外 = 重要性递增**。

## 6.3 压缩金字塔

触发：**仅由 token 阈值驱动**（`summarize_every` 步频扳机已退役）。

`advanceCompression`（pyramid.go:44-79）：

1. `compressBoundary`：keepRecent（默认 15）边界 + system 前缀全保留 + 首个 user 定位 + 避开孤立 tool 结果。
2. **增量条件**：prev 状态存在且 `prev.TailStart ∈ (segStart, recentStart]` → 续压新滑出段；否则**从头重压丢弃旧包**。
3. `summarizeSegment`：LLM 摘要（超时/熔断降级纯截断）。historySummarizer 是五段式结构（【决策/进展/待办/约束/文件要点】）。
4. 超 `maxBundles=20` → `mergeOldestBundles`（取一半 LLM merge，失败拼接截 3000 rune）。
5. 状态 upsert JSONB（`agent_compress_states`）。

`buildCompressedView`：`system 前缀 + 首条 user + renderBundles 摘要消息 + messages[TailStart:]`。

**懒加载**：`loadCompressStateOnce` 每 agent 只试一次；`TailStart > len(history)` 才丢弃状态。

**摘要器 402 熔断**：`summarizerDisabled` = 连续 balance errors ≥ 2（只认 "Insufficient Balance"/"402"）；熔断后全走截断降级**直到进程重启**（无冷却恢复）。

## 6.4 块记忆生命周期

### 写入（4 个触发点，全 best-effort）

| 触发 | outcome | 位置 |
|---|---|---|
| 子 Agent 成功 | success | dispatcher.go:3875 |
| 叶子 partial | partial | :3733 |
| 热驻 domain 成功 | success | idle_pool.go:865 |
| 失败打捞 | fail | salvage.go:104（source=salvage） |

`saveBlockMemory`：开关关/空内容跳过；factExtractor 可用先抽事实 → `saveFacts`（每条独立记录，`source=fact_extraction`+fact_index）；否则 `saveRawBlockMemory`（`"目标/角色/结果"` 三段式，goal 截 200、result 截 500）；随后 `bumpDomainProfile`。连续失败 ≥10 次 slog.Warn。

Meta 字段：goal/domain(roleID)/session_id/sub_agent_id/parent_id/task_domain/files_modified/outcome/reuse_count/domain_reuse_count/source。

### 召回（派发新子 Agent 时）

`injectScopedRecall`（dispatcher.go:5229-5279）四级回退：

1. **黑板 scope 优先**：`bb.Query(sid, parentID, taskDomain, query, topK=3, "")` —— SQL 按 `session_id+parent_id+task_domain` 三键过滤；query 非空加余弦阈值 0.4；query 空走纯 scope `created_at DESC`（省 embed）。
2. 回退语义召回 `SearchBlockMemoryByGoal`（session 内；**sessionID 空会退化为全局**）。
3. 不足 3 条 → 跨 session 补位 `SearchBlockMemoryCrossSession`（排除当前 session，阈值**更严** 0.5 vs 0.4）。
4. `rankBlockMemory`（outcome 0/1/2 → reuse_count 降序 → 新近优先）→ `bumpReuses`（jsonb_set reuse_count+1，**不动 last_accessed**）→ 渲染【相关记忆】（成功经验/避坑经验两段）+ 头部声明"已完成结论，仅作背景，不得当待办重复执行"。

`withPriorSalvage`/打捞槽走独立通道（不走通用注入）。

### 归档

`ArchiveStale`：`archived=true` 冷备（不删），查询层全局排除（10 处 SQL 都带 `archived=false`）；由 lifecycle 每日 tick。**注意**：块记忆的 `last_accessed` 恒 NULL（召回不调 IncrementAccessCount）→ 归档对块记忆实际失效（见坑 1）。

### 冷复活种子

`QueryBlockMemoryByDomain`（按 task_domain 成链）→ `domain_profile.go` 冷启动注入种子（cap 3 条）。

## 6.5 Embedding 多后端

`NewEmbedder` 分派：`""`/`pseudo` → PseudoEmbedder；`openai`/`local` → OpenAI 兼容 HTTP；`onnx` → 条件编译（`-tags onnx`）；default 报错。

- **PseudoEmbed**：SHA-256 桶计数 + L2 归一（牛顿迭代）；tokenize 小写 ASCII 词 + CJK 逐字。零依赖恒成功（离线兜底）。
- **OpenAIEmbedder**：`POST {base}/v1/embeddings`（**base_url 只写主机根路径**，客户端自拼 /v1/embeddings）；10s 超时；**3 连败 → 开路 60s**（开路期失败不计数防探测延长）；`httputil.RetryableClient`（3 次退避）；非 200/空 data/维度不匹配报错。
- **ONNX**：需 `model.onnx + tokenizer.json + config.json` 三件齐全，**缺一 fail-closed 不降级**；WordPiece 分词器（贪心最长前缀，`##` 续子词，失配回退 UNK）；mean pooling + L2；`mu` 保护 session。
- 维度自洽约束：`pgvector.dimensions` = `embed.dim` = ONNX hidden_size。

## 6.6 检索层（chunker/RRF/hybrid）

- `Chunk`（chunker.go）：按行/标题切块 + rune 重叠；空行/标题/超限硬收；**拼块时不补回 `\n`**。
- `rrfMerge`（rrf.go）：`score += 1/(60+rank+1)`，稳定排序截 topK；`byID` 是**后者覆盖前者**（最终记录对象来自最后一路）。
- `SearchHybrid`（hybrid.go）：`external_kb` 默认 type；embed 失败**直接报错**；单路失败仅 logf；两路都失败才报错。
- `IngestDir`：只处理**顶层** `.md/.txt`（不递归）；逐块 embed+Save，单块失败继续；meta 带 namespace/source/doc/chunk。
- `GlobalKnowledgeRetriever.Retrieve` 是 **dormant 路径**（依赖未接线直接报错）——真正在用的是 SearchHybrid 与 dispatcher 的 injectScopedRecall。

## 6.7 用户画像与项目偏好

- **Store**（userprofile/store.go）：RCU（读 atomic.Pointer 无锁、写 mu 串行）；文件缺失发布空 Profile 不报错；`Append` 定位/新建小节，追加 `- text（YYYY-MM-DD HH:MM）`（**全角括号**）。
- **人工行 vs 自动行**（merge.go）：尾部带时间戳 = Auto（可被合并重写）；否则 Human（原序保留在前，程序永不改写）。
- **MergePlan**：`merged` 是**完整替换**（空列表=清空该小节 Auto 行）；`archived` 进归档小节（cap 20）；`ApplyMerge` 文本相同回填旧时间戳去重。
- **ProjectStore**：按 `tool.WorkDirFromContext(ctx)` 优先解析路径（`<wd>/.bma/project_preferences.md`），per-path 缓存（**失败不缓存**，缓存只增不减）；多进程无跨进程锁。
- 演化的失败降级：merge 失败 → `Append(归档小节, 原始增量)`（fail-open 不丢）。

## 6.8 会话自进化（evolver 接线）

`evolveSession`（agent/evolver.go）：会话终态触发；≥5 事件才跑 / digest ≤1500 runes / 90s 超时；一次轻量 LLM 产出 `{user_prefs, project_lessons, skills[...]}` → PrefMerger 合并（user 目标小节 {偏好,技术栈,沟通风格}、project {项目经验}）→ skillSink 落库（bootstrap/evolver.go：阈值 skillUpdateDistance 0.25 相似度才更新、skillRecallDistance 0.4）→ evolution_log。

## 6.10 隐含约定与坑

1. **块记忆 `last_accessed` 恒 NULL → ArchiveStale 对块记忆实际失效**（召回路径不写该列）。
2. **`truncate()` 是字节截断**（与 rune 截断并存于 pipeline.go，别混用；中文会切出乱码）。
3. **`summarize_every` 已退役**（步频压缩曾致"反复失忆重读文件"）——别重新接上。
4. **摘要器 402 熔断不可恢复**（到进程重启）；表现为"上下文全截断无结构化摘要"且日志无显式错误。
5. **`summarizeTimeout` 代码默认 5s vs config 120s**——漏装配 `WithSummarizeTimeout` 会让思考型模型摘要全挂回退全量。
6. **RRF 注释与实现不符**（最后一路覆盖同 ID 记录）。
7. **chunker 丢换行**（markdown 结构被压平）。
8. **`SearchHybrid` 降级不对称**：embed 挂=硬失败；向量库挂=关键词仍可用。
9. **`SearchBlockMemoryByGoal` 空 sessionID 静默退化为全局检索**。
10. **跨 session 阈值更严**（0.5 vs 0.4）——宁可漏不可串味。
11. **fail/partial 不丢弃**（进"避坑经验"段）——过滤掉等于丢掉最贵的教训。
12. **金字塔"从头重压丢旧包"边界**：增量条件不满足时整段重压（摘要重写、缓存失效）；改 windowMessages/evict 顺序会触碰。
13. **三段注入全尾部追加**（前缀缓存约定）；新增注入器必须遵守。
14. **`loadCompressStateOnce`/`loadEventsOnce` 每 agent 只一次**：agentID 复用（热驻换任务）不会重拉 PG 状态；陈旧状态只要 TailStart 不越界就照用。
15. **`Write` 错误被丢弃**：事件落库失败静默丢失（PG 里有靠 lazy load 兜回；内存-only 场景永久丢）。
16. **userprofile 多实例同机并发写互相覆盖**（无跨进程锁）；**手写行加了全角时间戳后缀会被误判为 Auto**。
17. **`ApplyMerge` 的 merged 是完整替换**（不是增量）。
18. **IngestDir 部分失败静默容忍**（返回成功计数）。
19. **OpenAIEmbedder 冷却期失败不计数**：恢复需跨多个冷却周期攒 3 次失败（比预期慢）。
20. **onnx 后端 fail-closed**（缺文件启动失败，不降级 pseudo）。
21. **`compressMiddle` 是死代码**（仅测试引用）。
