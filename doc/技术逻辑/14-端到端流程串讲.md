## 14.1 全景骨架

```
用户 → POST /api/sessions（或 TUI 输入）
  → ReactService.CreateSession（PG session_history + 内存 registry）
  → goroutine runSession → 按 gear 选顶层角色（fast=doc_assistant / daily=domain / cluster=meta）
  → ReActAgent.RunWithHistory（主循环）
       ├─ 每轮：Assemble 上下文 → LLM → 工具
       ├─ 工具 = call_sub_agent → Dispatcher.dispatchOne → 子 ReActAgent（goroutine）
       │      ├─ 校验闸门（spec门/冒烟/L0/集成/runtime/visual/计分）
       │      ├─ 块记忆沉淀 + 打捞 + 看板/树/台账
       │      └─ notify → mailbox → 父 drainMailbox
       └─ 无 tool_calls 且无未决子 → 终答
  → agent_done 事件 → completed → 持久化 → SSE done 帧 → 通知
```

## 14.2 阶段一：创建会话

1. **HTTP**：`POST /api/sessions`（session_http.go:40）——DecodeBody → goal/gear/thinking 枚举校验 → workDirAbs（目录必须存在）→ 图片/视频限额 → `CreateSession`。
2. **ReactService.CreateSession**（service_react.go:996）：createMu 幂等闸（同 goal running 复用）→ 视频抽帧入 goal → `session-<epoch>-<rand>-<seq>` 建内存会话（Messages=[system "Goal: …", user goal]）→ gear/thinking 覆盖（默认取 config `agent.default_gear`）→ 首轮图片挂 `firstTurnImages` → 双上下文（runCtx + 独立 stopCtx）→ `EnsureProjectDoc` 异步 → `go runSession`。
3. **runSession**（:3009）：persist running → `resolveGearMetaRole` 选顶层角色 → provider（thinking 覆盖）→ 记忆包装（meta 档=看板/roster/台账 wrapper + metaSkillBlock；daily 档=roleSkillBlock）→ `NewReActAgent(session.ID, …)`（LiveEvents/SuspendOnChildWait/ProviderFunc/PendingChecker）→ runCtx 注入 sessionID/workDir/stopCtx/trustMode/图片 → goal 拼话题召回 + 技能预筛 → `agent.Run`。
4. **存储写**：`session_history` upsert（status=running）；`agent_tree_nodes`（后续子节点）；`session_events` 落 `session_start` 类 System 事件（前端 turns 识别为 system_start 跳过展示）。

## 14.3 阶段二：顶层 ReAct 循环（首轮）

主循环每轮（react_agent.go:599-932）：

1. `suspendGate.Park`（热驻挂起检查点）→ 顶部 `drainMailbox`（早前注入的用户/子 Agent 消息）。
2. `memory.Assemble`：压缩视图 + 尾部注入（【近期事件】+ 文件小地图；meta 再叠看板/空闲清单/台账；domain 叠【兄弟产出】）。
3. 视图变换：evictStaleToolResults → 时间尾部消息 → windowMessages → sanitizeToolPairing → 剥图（已知无视觉）→ tokenBudget 检查。
4. `ToBladesMessages` → `blades.ModelRequest`（Tools=Schema() **每轮实时**）→ `generate`（中间件链 RetryLLM→CallLLM→TerminalCall）→ 流式生成（llm_delta 推送 → handleLiveEvent 更新 StreamingText；think_delta 更新 ThinkingText）。
5. 响应处理：token usage 事件；坏工具调用/空响应保护；**无 tool_calls = 终答候选**（还要看未决子）；有 tool_calls → 并行/串行执行 → `tool_exec` 事件 → 入史 → 每轮工具后 drainMailbox → 停滞守卫。

**事件流**：每个 LiveEvent → `handleLiveEvent` → addEvent（内存 >500 裁 200）→ persistEvents（每轮 delete-then-insert 写 session_events）→ SSE 500ms 轮询差异推帧。

## 14.4 阶段三：派发子 Agent

1. **派发前**：顶层（meta）先 `WriteSpec`（goal+acceptance 必填 + 可选 files/verify_levels/contract/baseline）写进共享记忆槽 `<parentID>:spec[:domain]`；`WriteSharedMemory` 写自由槽（file_tree 单写者）。
2. **call_sub_agent(s)**（dispatcher.go:2366）：解析参数 → **同名热驻隐式复用** → 领域档案冷复活 → validateDispatchArgs（硬拒：缺 responsibility/超硬限/非法 mode；软警告：非中文领域名/超软限）→ **WriteSpec 强制门**（hasFreshSpec：missing/invalid/stale 三种拒绝文案）→ `dispatchOne`。
3. **dispatchOne**（:2579）：reuse 分流 → 角色/worktree 校验 → scout 墙钟兜底 → CanCall → 域控守卫（依赖门/同名活跃/复用守卫）→ withPriorSalvage → 接力熔断 → 全局限额 → 生成 ID → worktree 创建 → tools_hint 预挂载 → 技能解析 → trackChildStart → **热驻 domain 走 dispatchHotDomain，否则普通 goroutine**：
   - 树 Register + SetCancel；
   - 台账 RecordDispatch（仅 Meta 直派）；
   - 看板 boardAssign（in_progress）；
   - subMeta/activity 注册 + patrol；
   - `go runSubAgent`（defer CompareAndDelete 清理）；
   - 墙钟预警阶梯 + 侦察中点预警 goroutine。
4. **事件**：派发事件 `sub_agent_dispatch`（逐项落，含中文领域名 detail_json）→ 前端子 Agent 列表。

## 14.5 阶段四：子 Agent 执行与校验闸门

1. **runSubAgent → runSubAgentOnce**（:3485）：providerForAgent（实例覆盖优先）→ domain 命名（`<领域>领域Agent`）+ responsibility 身份头（SystemPrompt 末尾）→ 黑板摄取包装（domain）→ 构造 ReActAgent（工具白名单 adapter/心跳/live 转发含 recordFileWrite+recordRecentActivity）→ 前缀拼装（AGENTS.md → 共享记忆/spec → 项目偏好 → 经验技能 → 块记忆召回 → 领域标签 →【当前任务】）→ verifyKind 解析（executable 追加证据格式模板）→ `runEngine`（react/reflection/plan_execute）。
2. **子循环**：同 14.3（子 Agent 也能递归派发叶子；工具执行经同一 Registry/Guard/沙箱/审批链；WriteFile 缩水硬拒/快照/mtime 校验）。
3. **完成收尾闸门**（按序）：
   - L0 可执行证据（executable）→ 缺则反馈 1 轮 → errVerifyMissing；
   - LimitReached（domain 暂停 / 叶子部分返回）；
   - 冒烟层（spec.files ∩ 实写文件 → node --check 等）→ 反馈 1 轮 → errSmokeFailed；
   - JS 引用完整性第三档；
   - 集成层（HTML 入口引用图）；
   - runtime 探针（navigate+evaluate+console 无 error）；
   - visual 层（场景去重截图）；
   - acceptance 计分（quality 缺证据 → 硬判未验证）。
4. **沉淀**：`memory.Write(task_goal_summary)` → `saveBlockMemory`（factExtractor 提事实→saveFacts / 回退全文；outcome 标签；bumpDomainProfile）。
5. **机器校验段**：冒烟/集成/计分报告拼进 `MachineCheck` → 完成摘要（domain 终答缺【未验证项】段追加机器警告）。

## 14.6 阶段五：回传与整合

1. **notify**（:5371，唯一咽喉）：台账 RecordTerminal → 聚合拦截（map 模式）→ >4000 runes 回传落盘 `.bma/returns/`（摘要留 1500）→ mailbox Send（From=subAgentID）。
2. **父侧**：主循环 drainMailbox（顶部/无 tool_calls/工具后/wait 循环）→ `[mailbox from X]` user 消息入史 → 事件：普通=sub_agent_done、request/escalate=**peer_ask**（From=user 不推完成）→ memory.Write(sub_agent_summary)。
3. **父整合**：LLM 基于完整摘要重生成（drain 到新消息即 continue）；未决子>0 → waitForChildren（阻塞不烧轮次）/ PausedOnChild / SuspendOnChildWait（awaiting_child 挂起）。
4. **跨域契约检查**：兄弟全完成（count 归零）异步跑（变更屏障+指纹去重）→ 违例按文件归属打回。

## 14.7 阶段六：终态与交付

1. **顶层终答**：无 tool_calls 且无未决子 → `memory.Write(answer)` → ReactResult。
2. **runSession 收尾**：软停→pauseSession；成功→验收 RunWrap（可选）→ **先落 agent_done 事件** → completed → `evolveSession`（自进化，≥5 事件）→ persistHistory/persistEvents → finalizeSession（清 live 文本 → notifier webhook → evict 淘汰）。
3. **SSE**：轮询发现 status 非 running/awaiting → 推 `done` 帧 → 关连接；前端 onDone 对账重取快照 + 浏览器通知（页面隐藏时）。
4. **存储最终态**：session_history.status/completed、session_events 全量、agent_messages 全量覆盖、agent_tree_nodes 终态、块记忆沉淀。

## 14.8 支线：热驻复用 / 暂停恢复 / 复活返工 / 验收闭环

- **热驻**：domain 完成 → enterIdle（固化 gear + tree.Idle + armTTL）→ meta 每轮见【空闲领域Agent】清单 → 强相关任务 `call_sub_agent(reuse_agent_id=…)` → dispatchToIdleSlot（reuseCount++ 延寿 → opNewTask）→ 复用；TTL 到期/LRU/会话删 → destroySlot。
- **暂停恢复**（token 触限）：domain errPaused → 存 history + tree.Pause → 父 wait 检测 HasPausedChild → 会话 paused_on_child；用户"继续"（或 sendMessage）→ ResumePaused（LoadMessages 重建 + fresh budget，"继续"）→ 再触限/完成/出错三态；续跑上限 `maxPausedResumes`（默认 2）→ concludePaused 强制收口部分返回。
- **软停/取消**：Stop → SetSoftStop + StopRunning（树）+ 取消 run → 收尾分流（domain 落 Paused、叶子部分回灌）；cancel → error + cascadeCancelTree + PurgeSession 清理。
- **复活返工**：编排页直连终态子 Agent（MessageAgent）→ Tree.Reopen + ReviveWithMessage（种子=原任务+上轮结果+用户消息；mailbox Reopen；msgLogger Clear；看板翻回）→ 父收"复活返工，勿重复派发"；验收 FAIL 也走同路径。
- **验收闭环**（可选）：RunWrap → tester 验收 → PASS → demo 录播评审（fail-open）→ 打回归因 → reworkFailures。

## 14.9 一条时间线（事件流 × 存储写 × SSE 帧）

| # | 动作 | 事件流 | 存储写 | SSE 帧 |
|---|---|---|---|---|
| 1 | 创建会话 | system 启动 | session_history(running) | 首帧全量快照 |
| 2 | LLM 轮次 | token_usage（debug）；think（think_delta 累积）；assistant_text（口播） | session_events（每轮全量重写）；session_logs（llm_input/llm_output） | live 帧（streaming_text/thinking_text） |
| 3 | 工具调用 | tool_call/tool_exec（Registry 回调）；call_sub_agent 另落 sub_agent_dispatch | agent_messages 热写（Redis）+ 终态 PG | 增量 SessionEvent |
| 4 | 派发子 Agent | sub_agent_dispatch（每人一行） | agent_tree_nodes（Register）；agent_events（mailbox 留痕） | 增量 |
| 5 | 子 Agent 跑 | 子 Agent 的 LiveEvent 经 liveFn 转投会话（加【展示名】前缀）；token 计入会话累计 | 子 Agent 消息 Redis 热层 | live 帧 + 增量 |
| 6 | 子 Agent 完成 | sub_agent_done（或 peer_ask）；摘要 llm_result | agent_tree_nodes(Finish)；agent_messages 全量；块记忆沉淀 | 增量 |
| 7 | 终答 | agent_done（MetaAgent） | session_history(completed)；events 全量 | `done` 帧 → 关流 |
| 8 | 收尾 | — | 下次访问时 evict/淘汰 | 前端对账重取 |

## 14.10 关键不变量总结

1. **Agent 实例无状态**：一切续跑靠 history 传入/落库重建。
2. **信箱是"运行中干预"唯一触达通道**（主循环不读 Messages）。
3. **user 角色消息的注入时机**：只在 tool 结果齐全后或无 tool_calls 分支（配对 400 红线）。
4. **stable 提示词层跨轮字节稳定**（前缀缓存）；一切动态段尾部注入。
5. **notify 是终态唯一咽喉**（台账/聚合/落盘都挂它）。
6. **校验"自述不算证据"**：全部基于 history 里的工具调用记录。
7. **Tool schema 每轮实时读** → 插件热插拔/挂载下一轮生效。
8. **写文件三重防御**：缩水硬拒 / 快照 / mtime 陈旧警告；spec 失效写墓碑。
9. **失败结构化**：`[failure kind=X retryable=Y]` + 打捞 + 遗产清单；未验证三态化（黄）。
10. **存储写永远 best-effort**：失败只记日志，不阻塞执行（strict 只在启动期）。
