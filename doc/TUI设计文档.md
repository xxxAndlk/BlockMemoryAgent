# BlockMemoryAgent 终端 TUI 设计文档（v2.0）

> 目标：参考 Claude Code 的简洁终端交互，设计一个适合编程场景的 TUI 界面。核心要求：主对话始终可见、工具调用状态清晰、Agent 执行进度可观测、记忆召回可感知。

---

## 1. 设计原则

### 1.1 参考 Claude Code

Claude Code 的 TUI 是编程助手的体验天花板。它的核心设计：
- **主对话占满屏幕**：用户输入和 Agent 响应始终可见，不被面板遮挡
- **底部状态栏**：显示当前计划、工具调用、Agent 状态，一眼可见
- **简洁的标记**：用 `[●]` / `[✓]` 标记工具调用状态，用 `∘` / `●` 标记 Agent 状态
- **输入栏在底部**：符合终端习惯，输入后内容自动滚动到对话区

### 1.2 我们的差异化

在 Claude Code 的基础上，增加 BlockMemoryAgent 特有的能力展示：
- **记忆指示**：当 Agent 从长期记忆召回知识时，显示 `🧠 recalled: ...`
- **话题切换提示**：切换 SessionBlock 时，显示话题切换提示
- **计划进度**：在底部状态栏显示当前 Plan 的执行进度（如 `[2/5] ReadFile → WriteFile → RunTest`）
- **Agent 列表面板**：按 Tab 切换右侧折叠面板，显示当前活跃的 Agent 和它们的任务

## 2. 总体布局

```
┌──────────────────────────────────────────────────────────────┐
│  BlockMemoryAgent > session-001  ●running  3 agents active    │  ← 顶部状态栏
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  > 帮我修复这个 CSS 文件的样式问题                            │  ← 主对话区（80% 高度）
│                                                              │
│  好的，让我先检查文件内容...                                   │
│  [●] ReadFile: styles.css                                    │
│  [✓] ReadFile: styles.css  (1.2KB)                          │
│                                                              │
│  发现 `.header` 的 `padding` 值不正确...                       │
│  [●] WriteFile: styles.css                                   │
│  [✓] WriteFile: styles.css  (+3/-2 lines)                   │
│                                                              │
│  已修复。让我验证一下...                                       │
│  [●] RunCommand: npx stylelint styles.css                    │
│  [✓] RunCommand: npx stylelint styles.css  (exit 0)          │
│                                                              │
│  修复完成。`.header` 的 `padding` 从 `20px` 调整为 `16px`，    │
│  与 `.footer` 保持一致。                                       │
│                                                              │
│  🧠 recalled: 用户偏好用 Vue 3 + Composition API              │  ← 记忆指示（当召回时显示）
│                                                              │
├──────────────────────────────────────────────────────────────┤
│  [plan] 1.ReadFile → 2.WriteFile → 3.RunTest   [2/3] ✓       │  ← 计划进度栏
├──────────────────────────────────────────────────────────────┤
│  > _                                                         │  ← 输入栏
└──────────────────────────────────────────────────────────────┘
```

### 2.1 顶部状态栏

```
BlockMemoryAgent > session-001  ●running  3 agents active  in:12k out:3k
```

- `BlockMemoryAgent`：品牌名
- `session-001`：当前会话 ID
- `●running`：会话状态（`●running` / `◐awaiting` / `✓completed` / `✗error`）
- `3 agents active`：当前活跃的 Agent 数量
- `in:12k out:3k`：累计 token 消耗（input / output）

### 2.2 主对话区（80% 屏幕高度）

滚动显示用户输入和 Agent 响应。关键元素：

**用户输入**：
```
> 帮我修复这个 CSS 文件的样式问题
```
- 前缀 `>` 表示用户输入
- 高亮显示

**Agent 响应**：
```
好的，让我先检查文件内容...
```
- 普通文本，无特殊前缀

**工具调用**：
```
[●] ReadFile: styles.css
[✓] ReadFile: styles.css  (1.2KB)
```
- `[●]`：工具调用中（黄色）
- `[✓]`：工具调用成功（绿色）
- `[✗]`：工具调用失败（红色）
- 工具名 + 目标 + 结果摘要

**记忆指示**：
```
🧠 recalled: 用户偏好用 Vue 3 + Composition API
🧠 recalled: 项目编码规范：优先使用 TypeScript，不用 any
```
- `🧠`：记忆召回标记
- 显示召回的记忆片段（最多 2 条，避免信息过载）
- 灰色显示，不干扰主对话阅读

**话题切换提示**：
```
─── 切换话题：从 [CSS 修复] 到 [JS 重构] ───
```
- 当用户切换话题时显示
- 分隔线样式，提示话题切换

### 2.3 计划进度栏

```
[plan] 1.ReadFile → 2.WriteFile → 3.RunTest   [2/3] ✓
```

- `[plan]`：计划标记
- `1.ReadFile → 2.WriteFile → 3.RunTest`：当前计划步骤
- `[2/3]`：当前执行到第 2 步，共 3 步
- `✓`：当前步骤已完成（如果是 `[2/3] ●` 表示正在执行第 2 步）

当没有执行计划时（简单任务直接回答），显示：
```
[direct] 直接回答
```

当执行工具调用时（不走 Plan），显示：
```
[tool] ReadFile: styles.css   [●]
```

### 2.4 输入栏

```
> _
```

- 固定前缀 `>`
- 光标闪烁
- 输入内容实时显示
- 支持多行输入（Alt+Enter 换行）
- 支持历史输入（↑/↓ 切换）

**输入模式**：
- 普通模式：直接发送到当前会话
- `/clear`：清空当前会话的对话历史（不删除记忆）
- `/topic <name>`：切换到指定话题（创建新的 SessionBlock）
- `/topics`：列出所有话题
- `/memory <query>`：手动查询长期记忆
- `/agents`：切换右侧 Agent 面板
- `/help`：显示帮助

### 2.5 右侧 Agent 面板（按 Tab 切换）

按 `Tab` 键折叠/展开右侧 Agent 面板：

```
┌────────────────────────────────────┬────────────────────┐
│  主对话区（80%）                    │  Agent 面板（20%）   │
│                                    │                    │
│  > 帮我修复这个 CSS 文件的样式问题  │  ● Agent-1          │
│                                    │    CSS 修复负责人   │
│  好的，让我先检查文件内容...        │    [2/3] ReadFile   │
│                                    │                    │
│                                    │  ○ Agent-2          │
│                                    │    JS 重构负责人    │
│                                    │    [等待中]         │
│                                    │                    │
│                                    │  🧠 召回记忆：        │
│                                    │  - Vue 3 偏好       │
│                                    │  - 编码规范         │
│                                    │                    │
└────────────────────────────────────┴────────────────────┘
```

Agent 面板内容：
- 当前活跃的 Agent 列表（名称、状态、当前任务）
- 每个 Agent 的执行计划进度
- 最近召回的记忆片段（2-3 条）
- 当前会话的 token 消耗统计

**键位**：
- `Tab`：折叠/展开 Agent 面板
- 面板展开时，主对话区宽度自适应（80% → 60%）

## 3. 状态标记与颜色

### 3.1 会话状态

| 状态 | 标记 | 颜色 | 说明 |
|------|------|------|------|
| running | ● | 绿色 | 正在执行 |
| awaiting | ◐ | 黄色 | 等待用户输入或工具结果 |
| completed | ✓ | 灰色 | 已完成 |
| error | ✗ | 红色 | 执行出错 |

### 3.2 Agent 状态

| 状态 | 标记 | 颜色 | 说明 |
|------|------|------|------|
| active | ● | 绿色 | 正在执行 |
| idle | ○ | 灰色 | 空闲，等待分配任务 |
| done | ✓ | 灰色 | 已完成 |
| error | ✗ | 红色 | 执行出错 |

### 3.3 工具调用状态

| 状态 | 标记 | 颜色 | 说明 |
|------|------|------|------|
| running | [●] | 黄色 | 工具调用中 |
| success | [✓] | 绿色 | 工具调用成功 |
| failed | [✗] | 红色 | 工具调用失败 |

### 3.4 记忆指示

| 类型 | 标记 | 颜色 | 说明 |
|------|------|------|------|
| 召回记忆 | 🧠 | 灰色 | 从长期记忆召回的知识 |
| 话题切换 | ─── | 蓝色 | 话题切换提示 |
| 压缩提示 | 📦 | 灰色 | 记忆被压缩的提示（调试模式） |

## 4. 交互设计

### 4.1 键位映射

| 键 | 作用 | 说明 |
|----|------|------|
| `Enter` | 提交输入 | 发送消息到当前会话 |
| `Alt+Enter` | 换行 | 多行输入 |
| `↑` / `↓` | 历史输入 | 切换历史输入记录 |
| `Tab` | 切换 Agent 面板 | 折叠/展开右侧 Agent 面板 |
| `Ctrl+C` | 取消 | 取消当前正在执行的 Agent 循环 |
| `Ctrl+L` | 完整记录面板 | 打开/关闭可滚动的完整对话记录面板（4 同效） |
| `Q` / `q` | 退出 | 退出 TUI |
| `?` | 帮助 | 显示键位帮助 |

### 4.2 命令模式

以 `/` 开头的输入进入命令模式：

| 命令 | 作用 | 示例 |
|------|------|------|
| `/clear` | 清空当前对话历史 | `/clear` |
| `/topic <name>` | 切换到指定话题 | `/topic CSS修复` |
| `/topics` | 列出所有话题 | `/topics` |
| `/memory <query>` | 手动查询长期记忆 | `/memory Vue 3 偏好` |
| `/agents` | 切换 Agent 面板 | `/agents` |
| `/status` | 显示当前会话状态 | `/status` |
| `/help` | 显示帮助 | `/help` |

### 4.3 滚动与导航

- 主对话区支持 `PgUp` / `PgDn` 滚动
- Agent 面板支持 `↑` / `↓` 导航
- 鼠标滚轮支持（如果终端支持）

## 5. 数据流与刷新策略

### 5.1 刷新频率

| 组件 | 频率 | 触发方式 |
|------|------|----------|
| 主对话区 | 实时 | 事件驱动（用户输入/Agent 响应/工具结果） |
| 计划进度栏 | 实时 | 每步 Execute/Reflect 后更新 |
| Agent 面板 | 1s | Tick 轮询（Agent 状态变化） |
| 顶部状态栏 | 1s | Tick 轮询（token 消耗、Agent 数量） |

### 5.2 事件驱动更新

TUI 通过事件通道接收后端推送：
- 用户输入 → 立即显示在主对话区
- Agent 响应 → 流式显示在主对话区（逐字输出）
- 工具调用 → 显示 `[●]` 标记，成功后更新为 `[✓]`
- 记忆召回 → 显示 `🧠 recalled: ...`
- 话题切换 → 显示分隔线提示

## 7. 实现顺序

1. **骨架**：单列布局（顶部状态栏 + 主对话区 + 输入栏）
2. **主对话区**：用户输入、Agent 响应、工具调用标记、流式输出
3. **计划进度栏**：显示当前计划步骤和进度
4. **记忆指示**：召回记忆时显示 `🧠 recalled: ...`
5. **Agent 面板**：右侧可折叠面板，显示 Agent 列表和状态
6. **话题切换**：分隔线提示、命令模式 `/topic`
7. **命令模式**：`/clear` / `/topics` / `/memory` / `/help`
8. **性能优化**：事件驱动更新、避免频繁重绘
