## 3. 本轮新增阻塞缺陷

### P0-1：受控字面通道可再次批量修改全部间距

代码位置：`backend/internal/domain/tool/builtin.go:848-885,948-979`。

本轮新增 `semantic_literal_rationale` 后，模型只要自行填写不少于 8 个字，就能在 enforce 下回到旧字面替换。该通道没有禁止 `replace_all`，也没有把“唯一匹配”作为硬条件。

独立用例输入：

- 文件同时含 `.a { margin-bottom: 60px; }` 与 `.b { margin-bottom: 60px; }`；
- enforce 已开启；
- 参数携带 `replace_all=true` 和一段理由文本。

实测返回 `Success=true`、`replaced 2 occurrence(s)`，两个选择器均被改为 `24px`。这与“只让改一个间距，却把之前所有间距都改掉”的原始事故属于同一风险类别。

**返修要求**：模型自述理由不能成为绕过语义硬门的授权事实。优先删除该旁路；若确实保留受控通道，必须禁止 `replace_all`、多匹配和模糊多区域替换，要求唯一目标、预期指纹与最小 diff，并明确其授权来源。补“相同间距出现在多个选择器/多个文件”的生产级负面用例。

### P0-2：执行前 requested/resolved 审计失败仍继续生产写入

代码位置：`backend/internal/domain/tool/action_pipeline.go:288-300`。

requested 和 resolved 仍直接调用 `p.emit` 并忽略错误。本轮只修了 executed/mutation/scope/committed 等后续阶段，没有形成全阶段审计一致性。

独立用例让 sink 仅在 `requested` 失败，实测：

- 日志出现 `append event failed ... phase=requested`；
- 生产函数仍执行，`executed=true`；
- 最终仍返回 `Success=true`。

此外，scope_violated、rolled_back、manual_recovery_required 等路径仍有非 critical 的 `p.emit`，与 `emitAfterExecution` 注释宣称的覆盖范围不一致。

**返修要求**：requested/resolved 在执行前失败必须阻断；rollback/manual recovery 等审计失败必须进入明确的持久化恢复协议。逐阶段故障注入不能只覆盖成功路径的四个事件。

### P0-3：纯中文文件名被解析成只有扩展名

代码位置：`backend/internal/team/scope_resolver.go:275-330`。

`stripHanVerbPrefix` 把扩展名前所有前导汉字都视为中文动词。独立用例在工作区真实创建 `样式.css`，输入 `修改样式.css的间距`，实测 WriteSet 为：

```text
path:.css
```

而不是 `样式.css`，还附加“路径不存在（按允许新建处理）：.css”。这会授权错误资源，并让真正目标文件失去合同授权。

**返修要求**：不能用“前导汉字 + ASCII/点号”直接推断动词前缀。优先利用工作区真实候选、路径边界和最长匹配；对不存在的新文件无法消歧时必须标记 Ambiguous 并澄清，不能擅自删除文件名。补纯中文文件名、中文+ASCII 文件名、中文目录、动词粘连、拟新建文件等测试。

## 4. Go→Node worker 仍未通过 Windows 复验

整改记录称在 WSL 连跑 12 次全绿，并将根因定为超时后的并发读竞态。当前代码确已加入超时杀进程、局部 reader、空行跳过和错误诊断。

但在本机 Windows 验收环境：

```text
go test ./internal/domain/edit -run TestWorker_EndToEndCSSPlan -count=12
```

12 次均在 ping 阶段以 `semantic-edit: read: EOF (code=-32099)` 失败；全量后端测试中同一用例再次失败，语义最小编辑正例也因此失败。

这说明 WSL 通过不能覆盖 Windows 桌面目标环境。当前 shell 的 `node` 是 shim，而 Node 独立测试 15/15 通过；需要用**真实 Windows `node.exe` 和最终桌面包内 `node.exe`**分别复验，并保留当前 shim 环境的兼容/明确拒绝诊断。不能把本轮结果写成“worker 稳定性已验收通过”，也不能在没有新证据时继续断言只是同一随机竞态。
