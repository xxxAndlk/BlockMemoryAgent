## 待完成
1.当前Agent只有ReAct循环，需要加上Plan-and-Execute与Self-Reflection
    ReAct (推理-行动循环)：这是一种“动态决策与执行”的核心工作框架。它让Agent像人一样，在“思考”（Thought）、“行动”（Action）和“观察”（Observation）的循环中解决问题。每一步都基于当前情况动态策。
    Plan-and-Execute (计划-执行)：这是一种“顶层任务规划”策略。它要求Agent在行动前，先生成一个完整的、多步骤的任务计划，然后按计划逐步执行。这确保了Agent有清晰的方向。
    Self-Reflection (自我反思)：这是一种“自我评估与优化”的增强机制。它让Agent能够审视自己的行为结果，识别错误并吸取教训，从而在下一次行动或计划中改进。
1.1 在“计划”中融入“反思”：Agent可以先制定一个计划（Plan-and-Execute），在执行过程中，通过自我反思（Self-Reflection）来评估每一步的效果。如果发现计划有问题，就动态调整后续步骤。
1.2 在“循环”中加入“反思”：Agent可以运行ReAct循环，在每次行动和观察之后，加入一个自我反思的步骤，评估这次行动的质量，并指导下一步的思考和行动
最后总结：
规划：接到任务后，先使用Plan-and-Execute生成一个详细的行动计划。
执行与反思：在按计划执行时，启动ReAct循环来处理每个子任务。每执行一步，都通过Self-Reflection进行评估。
动态调整：根据反思结果，Agent可能修正当前的行动（ReAct的“思考”环节），也可能返回去修改最初的整体计划
